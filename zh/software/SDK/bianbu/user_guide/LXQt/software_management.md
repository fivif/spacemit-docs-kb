## 软件包管理器：APT

`APT`（Advanced Package Tool）是本系统的默认软件包管理器，用于管理 Debian 及其衍生发行版的软件包。`APT` 主要提供以下功能：

- **安装软件**：从官方软件源获取并安装所需软件包。
- **更新系统**：同步索引并升级已安装的软件包。
- **卸载软件**：移除不需要的软件包及其不再使用的依赖。
- **依赖管理**：自动解析并处理软件包之间的依赖关系，避免冲突。
