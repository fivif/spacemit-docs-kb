# 镜像

我们每个发布的版本都会提供预编译好的镜像，供体验。Buildroot 默认的镜像是`zip`格式，适用于 Titan Flasher，亦可解压后，用 fastboot 刷机。

## 下载

镜像地址：[Buildroot Image](https://archive.spacemit.com/image/k1/version/bianbu-linux/)。

## 刷机

Titan Flasher刷机参考[刷机工具使用手册](../../../../tools/user_guide/flasher_user_guide.md)。
