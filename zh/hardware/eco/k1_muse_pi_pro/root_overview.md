# K1 MUSE Pi Pro 简介

**[PDF 版本](https://cdn-resource.spacemit.com/file/product/K1/MUSE_Pi_Pro_brief_zh.pdf)**

**紧凑高效，助力 AI 与物联网的未来**

K1 MUSE Pi Pro 单板计算机将 RISC-V 八核处理器、存储硬盘、通用接口部件和扩展接口布置在同一块电路板上，支持 UEFI 启动以及多种操作系统和应用的运行，是一款完整的计算机系统产品。

K1 MUSE Pi Pro 为 1.8 寸单板，能够满足大语言模型应用、机器人、教育科研和物联网等场景中低功耗、空间紧凑情况下的算力需求，为 AI 新时代提供计算能力和丰富的接口扩展。

## 特性

- **紧凑型设计**
  信用卡大小的 1.8 寸单板计算机  

- **支持 UEFI 启动和配置**
  可选择启动介质和个性化配置计算机  

- **完全开源**
  提供板级、结构和软件包等设计资料和应用指导  

- **支持 GRUB 引导**
  可安装多个操作系统，由用户自行选择运行  

- **国产化自主创新**
  国产化自主创新方案，保障供应连续性  

- **标准 IO 扩展接口**
  标准 miniPCIe 和 M.2 定义的 IO 扩展接口，兼容行业主流部件  

- **高可靠性设计**
  高可靠结构应力保护、防静电能力与电磁兼容
