# 2.3 System Dependency Installation

You can quickly install all required dependencies for **BRDK**, **JDK**, and **ROS 2** using the desktop shortcut.

1. **Launch the installer**

   Double-click the **Development Environment Installation** icon on the desktop:

![](https://cdn-resource.spacemit.com/ros/docs-ros/en/k1/02_System_configuration/images/desktop.jpg)

2. **Execute the installer**

   In the pop-up window, click **Execute**:

![](https://cdn-resource.spacemit.com/ros/docs-ros/en/k1/02_System_configuration/images/image1.png)

3. **Select dependencies and confirm**

   - Choose the components you want to install.
   - Click **Confirm**.
   - A password prompt will appear; enter the default password: **bianbu**.

![](https://cdn-resource.spacemit.com/ros/docs-ros/en/k1/02_System_configuration/images/image.png)
